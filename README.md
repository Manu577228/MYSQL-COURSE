# 📘 SQL Course Materials 
A complete beginner-friendly SQL learning kit containing examples, exercises, cheat sheets, and visual explanations.  
Perfect for students, developers, and anyone preparing for interviews.

---

## ⭐ Features  
- ✔️ Visual examples for each SQL concept  
- ✔️ Beginner to intermediate level SQL coverage  
- ✔️ Includes JOINs, WHERE, LIKE, REGEXP, UNION, and more  
- ✔️ Exercises to practice your learning  
- ✔️ SQL Cheat Sheet (PDF) included  
- ✔️ Ideal for self-study or teaching material
